Naruto Online (Oasis Games) — Gear & Magatama JSON Pack
-------------------------------------------------------
Files:
  - slot_map.json           : Equipment slot → primary stat → accepted magatama
  - equipment.json          : Per slot gear tiers with base & per-level stat growth
  - magatama.json           : Standard Magatama types, stat table L1–L8, fusion EXP curve
  - rainbow_magatama.json   : Charm-gated sockets & example hybrid bonuses
  - charms.json             : Charm overview and milestones (3/6/9)
  - refine_stats.json       : Common secondary stats from Refine/Purify systems

Notes:
  • Numbers reflect widely referenced in-game examples. If your server build differs, adjust values in equipment.json.
  • Slot–stat mapping is consistent: Weapon→Attack, Clothes→Defense, Headgear→Life, Scroll→Ninjutsu, Accessory→Resistance.
  • Rainbow Magatama require charm levels 3/6/9 for 1/2/3 sockets.
